# Tomato Leaf Disease Detection

A deep learning based tomato leaf disease detection system developed using Convolutional Neural Networks (CNN), TensorFlow, and Keras. This project is trained on a real field tomato leaf dataset to classify and detect multiple tomato plant diseases from leaf images.

---

## Project Overview

This project focuses on identifying tomato leaf diseases using image classification techniques in deep learning. The model analyzes leaf images and predicts the disease category, helping in early disease detection and improving crop management.

---

## Features

- CNN-based image classification
- Tomato leaf disease prediction
- Real field dataset support
- Image preprocessing and augmentation
- Model training and evaluation using TensorFlow/Keras
- Google Colab implementation
